Code generator / After you download

Your file is downloaded. Here is what to do with it.

Thank you. Your configuration helps us see how the system is really used. The rest of this page walks the file onto the board.

  1. 1

    Open the file

    Find the .ino file in your downloads folder and open it with the Arduino IDE. The IDE will offer to move it into a folder of the same name. Say yes; that is how Arduino sketches are stored.

  2. 2

    Choose the board and the port

    Plug the Arduino into your computer with a USB cable. In the IDE, set Tools › Board to Arduino Uno, then set Tools › Port to the port that appeared when you plugged it in. If no port appeared, try a different USB cable: many cables carry power but no data.

  3. 3

    Upload

    Press the upload arrow. The sketch only uses LiquidCrystal, which ships with the IDE, so there is nothing to install. When the IDE says Done uploading, the display starts showing readings.

  4. 4

    Read the screen

    The top line shows the port, the short sensor name and the value, like A2 WM200SS 34 kPa. The bottom line shows the bar, state or warning you chose. Press the shield's left and right buttons to step through your sensors. The backlight goes out after five minutes without a button press; any button wakes it.

If something looks wrong

The screen is blank or shows blocks
Turn the contrast potentiometer on the LCD shield. A fresh shield is often set to full contrast, which shows solid blocks, or to none, which shows nothing.
A port reads No Sensor
Nothing is detected on that pin. Check the wiring at both ends. On a Watermark going through the 200SS-VA3 adapter, remember the adapter refreshes each channel every five minutes and holds the previous value in between, so give it time after powering up.
The percentage looks backwards
Higher percentages always mean wetter soil, in every measurement except the raw reading, which reports the sensor faithfully. If a capacitive probe reads backwards, your air and water calibration values are probably swapped. Generate a raw-value sketch, note the reading in open air and in water, then put those two numbers back into the form.
A battery warning appears
The sketch measures the supply against the chip's internal 1.1 V reference. It only works on battery power through the barrel jack. On USB power, including a USB power bank, the reading is not meaningful and the warning can be ignored.
The numbers do not match my soil
Calibration values and soil-texture thresholds are your field's, not ours. The defaults are a starting point. Change them in the form and generate the file again.

Coming back later

Your configuration is saved in this browser. Open the generator again and load it from the list at the top of the form, adjust what changed, and download a new file. Nothing is overwritten: tick the date-stamp option if you want each download kept separately.
