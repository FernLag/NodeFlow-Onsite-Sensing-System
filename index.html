NodeFlow(On-site) Sensing System Code Generator

This website allows you to generate the code the NodeFlow (On-site) Sensing System uses to read the sensors that you will plug in, and generate the information you are interested in.

The full instructions, from installing the Arduino software to reading the screen, are in the user guide. Open the user guide (PDF) The printable guide is being prepared. The guide is in English for now. A Spanish translation is on its way.

Videos on how to use the device are still to be added.

To generate the code for your NodeFlow (On-site) device, you will need to know:

  • What sensors you want to connect
  • How you will connect these sensors to the Arduino ports, i.e. to which port each sensor will be connected to. N.B. you can only connect one type of sensor to each port.
  • For each sensor, what variable should appear on your LCD screen
  • The visualization format for each of these variables

Working offline? This tool works without an internet connection, but you must open it online at least once first so it can load.

Clearing your browser's cache or site data for this page removes the offline copy.
